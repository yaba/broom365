1. Database

The database must already exist; Broom365 creates its tables in it. The user needs db_owner, or db_ddladmin + db_datareader + db_datawriter, on that database only.

More options

Any option of the Microsoft ODBC driver, written Name=value.

Simple and enough for one person or a small team. The data goes to {{ sqlite_file }}; in Docker keep that folder on a volume.

2. Encryption key

Protects the Microsoft 365 client secret that Broom365 stores in the database. A random one is suggested. It is saved on this server in {{ where }}. Keep a copy somewhere safe: without it the stored secret cannot be read again.
